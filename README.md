# T3 Code, Quieter

A concept redesign of the T3 Code desktop app, compared side by side with the app as it ships today.

Open `index.html`. The page needs no build step.

## Contents

- `index.html`: the landing page.
- `windows/today.html`: T3 Code as it ships today, recreated at 2000×809 with sample threads.
- `windows/redesign.html`: the redesign at 1600×960. It replays a working run in a loop; add `?static` to show the finished run without motion.
- `windows/redesign-fanout.html`, `windows/redesign-compare.html`, `windows/redesign-accounts.html`: the Fan out and Compare modes, and the Accounts picker open.
- `windows/redesign-merged.html`: the thread after its pull request merged, with Clean up enabled.
- `fonts/`: Selawik, the open fallback for Segoe UI.

## Hosting on GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open Settings, then Pages.
3. Set the source to the `main` branch, root folder.
