Concept redesign · T3 Code desktop

The same app,
with every color earning its place.

T3 Code is where you run coding agents across many projects at once. This redesign keeps its layout and labels, moves it onto one grey ramp with square corners, and gives color a job: state, project, account and tool kind. Then it rebuilds the prompt box for sending one task to many agents.

Sidebar · thread list

Rows you can read without reading them

Today every row spends three lines on the same layout, project name first, whether or not there is a branch to show. The redesign leads with the title and pushes everything else into marks you learn once.

  • Project mark: the first two letters of the project in its own hue (T3, AC, DO) replace the project name line.
  • Status top right: age, Done or Working sit where your eye lands after the title.
  • Provider logo tinted by account: the Claude mark is orange for the Work account and blue for Personal.
  • Child runs nest under their thread: a run started from a thread is listed beneath it with its own status.
  • Freshness wash: a faint green-to-red tint shows how long since a row last changed, on a log scale from 5 minutes to 6 hours.
  • Selection is a quiet purple, the only place purple appears.
Sidebar · bottom

Running work stays in one place

Working and Settled keep their labels. They are pinned to the bottom of the sidebar and open upward, so the list above never jumps when a run starts or ends.

  • Queued joins them as its own section with Launch all. New
  • Counts sit in the label, the way T3 Code already writes Settled (128).
  • Bottom icons and the update dot are unchanged; the dot takes the accent.
Transcript · working feed

Whose voice, and what kind of step

T3 Code already separates prose from tool steps with indentation and shading. The redesign keeps that and adds two small signals: tool icons are colored by kind, and thinking icons take the color of the account doing the work.

  • Tool kinds: commands citron, reads and searches cyan, edits clay, mixed steps violet. The same colors everywhere a tool step appears, including Changed files.
  • Account voice: the reasoning clock, the brain icons and the Thinking marker are Work orange because the Work account is answering.
  • Header: a spinning Working label with a live timer and the model that is running, in its account color.
  • Prose stays bright, steps stay dim, so the agent's words read first.
Composer · in a thread

The prompt box knows which account it is spending

Inside a thread you are talking to one agent, so the composer stays compact and keeps T3 Code's pickers and tray. What changes is what the controls tell you.

  • Modes: Thread, Fan out and Compare sit above the input, switched with Shift Tab.
  • Model in account color: the name is tinted by the account that takes the next turn.
  • RR · 2: round-robin across two Claude accounts, on by default when a model has more than one. New
  • Stop pulses while a run is live; send is a square in the accent.
  • Clean up sits beside Worktree and appears only when the thread runs in a worktree. It stays disabled while agents work or the pull request is open, and turns green once the PR merges and the thread settles. New
Thread panel

Same panel, square and a little louder where it matters

Every row of T3 Code's floating panel survives: device, editor, project script, branch, pull request, commit, changes and lineage.

  • The open pull request is green, matching the Done and PR color used everywhere else.
  • Changes shows lines added and removed in the same green and red as the transcript.
  • The transcript and composer move left to make room, so nothing hides under the panel.
New in this design New

One task, many agents

Fan out and Compare turn the prompt box into a launcher. The run list sits above the input, so the input never changes size, and every run shows its project and account before you send it.

  • Fan out: one prompt, one run per project; {project} fills in for each target.
  • Compare: the same task on several agents or accounts, each in its own worktree.
  • Accounts picker: choose which accounts a task may use, with each account's usage this window, and switch round-robin on or off.
  • Runs a launch starts appear in the sidebar under the thread that started them.
Color system

Every color has one job

Greys carry structure, one accent carries action, and everything with a hue means something you can learn: a state, a project, an account or a kind of tool step. All hues share T3 Code blue's saturation and lightness, so none of them shouts over the others.

  • Surfaces step up one level per layer: title bar, sidebar, window, then anything framed or floating.
  • Hover is grey; selection is purple and nothing else is.
  • Text uses four levels only. Every level clears 4.5:1 on the sidebar.
  • T3 Code blue measures 3.8:1, so it is used on semibold labels and icons, never body text.

What ships today

Restyle versus new feature

Most of this page restyles what T3 Code already does. A few controls need new work in the app. This table is based on T3 Code's orchestration v2 documentation and source.

  • Orchestration v2 already lets agents create threads, delegate tasks to any provider and queue follow-ups through its MCP tools.
  • The new controls give those abilities to the person at the keyboard.
